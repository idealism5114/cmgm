# D0B-NoSwitchKL

唯一消融是 **有效 switch KL 权重恒为0**。Prediction objective 仍为原始 L1+L5+L10+L20，每项 Huber delta=.02；validation、scheduler、early stopping 和 checkpoint selection 仍使用该四项总和。原 prior/posterior recursion、KL计算、alpha=.5、架构及 optimizer 不变。

Filter 内部原 beta 日程保留为诊断 reference；训练从独立零值取得 switch loss，不把 KL 梯度图接入 backward。因此 reference_schedule_beta 可以非零，而 beta_effective 和 actual weighted switch loss 始终为0。
